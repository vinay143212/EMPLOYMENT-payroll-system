Employee Payroll Management System

📌 Project Overview

The Employee Payroll Management System is a MySQL database project designed to manage employee payroll information efficiently. It stores employee details, department information, attendance, and salary records using relational database tables.

✨ Features

- Add and manage employee records
- Store department information
- Maintain payroll details
- Calculate employee salaries
- Generate payroll reports
- Use SQL queries for data retrieval and analysis

🛠 Technologies Used

- MySQL
- SQL

📂 Database Tables

- Employee
- Department
- Attendance
- Payroll

🚀 How to Run

1. Install MySQL Server.
2. Open MySQL Workbench or any MySQL client.
3. Create a new database.
4. Import or run the SQL script ("employee_payroll.sql").
5. Execute the SQL queries to create tables and insert sample data.

📖 Sample SQL Operations

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- JOIN
- GROUP BY

🎯 Learning Outcomes

- Database design using MySQL
- Writing SQL queries
- Managing relational databases
- Understanding primary and foreign keys
- Performing CRUD operations
